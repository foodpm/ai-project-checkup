# SEO 体检（网站项目可选）

> 检查项编号：SEO-01 至 SEO-33
>
> **本文是可选检查**：仅适用于有公开页面、希望从搜索引擎获得自然流量的网站项目（官网、博客、电商、内容站、SaaS 营销页等）。纯后台系统、API 服务、内网工具、App/小程序可以整篇标记「不适用」。
>
> 思路来源：《SEO实战密码》（昝辉/Zac）第 3～5、7、8、10、13 章，已提炼为可执行的检查清单。核心观念：搜索引擎的目标是满足搜索用户，排名三支柱是**相关性、权威性、实用性**；解决基本问题就解决了 95% 的问题，细节优化贡献不超过 5%。

## 0. 使用方式与结论口径

每项检查只使用四种结论之一：**通过 / 不通过 / 待核验 / 不适用**（不适用必须写理由）。结论必须有证据：能指到 文件:行号、HTML 源码片段、HTTP 状态码输出或站长工具截图。

**执行顺序建议**（收到体检报告后按此整改）：

1. 先跑 SEO-01 / SEO-02（收录比例 + 网管工具）定位大问题；
2. 排查 SEO-03 蜘蛛陷阱与 SEO-04/05 robots（致命级）；
3. 处理 SEO-08/09 规范化与复制内容（权重集中）；
4. 修 SEO-07/11/12（URL、内链、404）+ 补网站地图；
5. 逐页落实 C 部分（Title > H1/正文 > ALT > 描述 > 其余）；
6. 网站已有流量与排名时，加做 D/E 部分（风险与惩罚检测）——出现叠加作弊信号应优先「去优化」，再谈新优化。

## A. 全站收录与快速诊断

### SEO-01 页面收录比例

- **检查什么**：搜索引擎收录页面数 / 网站实际总页面数。
- **怎么查**：先统计真实页面总数（CMS 后台/数据库）；再用 Google/Bing 网管工具或 `site:` 指令查收录数。
- **合格**：收录比例 ≥ 60%。
- **不合格**：20%～30% 说明网站结构有很大问题——按 SEO-03/04/11 排查蜘蛛陷阱、robots 误禁、导航链接结构缺陷。

### SEO-02 网管工具全面体检

- **检查什么**：被黑/惩罚留言、抓取错误与抓取频率、HTML 建议（重复标题/元说明）、外链及锚文字、网站内容主题词、内部链接数。
- **怎么查**：注册并查看 Google Search Console / Bing 站长工具各板块。
- **合格**：无重大问题留言；抓取频率与站点规模匹配；最常见关键词与网站主题一致（出现 Reply/says 等模板噪声词说明模板文字占比过高）。
- **不合格**：404 大量堆积、抓取量过低、重复标题/元说明——逐项按后续检查修复。

## B. 网站结构优化

### SEO-03 蜘蛛陷阱

- **检查什么**：整站大 Flash、URL 中的 Session ID、301 以外的跳转（302/JS/Meta Refresh）、框架结构（Frame）、大量参数的动态 URL、JS/Flash 生成的导航、需登录才能看的内容、强制 Cookies。
- **怎么查**：查看首页及重要页面源代码，确认链接是普通 HTML `<a>` 标签；用网管工具「模拟蜘蛛抓取」对比蜘蛛所见与用户所见；检查 URL 是否含 sid/session 参数。
- **合格**：整站以 HTML 文字为主，导航与正文链接均为标准 HTML 链接，无 Session ID、无框架、无非 301 跳转。
- **不合格**：任一陷阱存在即不通过。改法：Flash 处加 HTML 链接入口；Session ID 改用 cookies；跳转统一 301；导航用 CSS 实现；会员内容放弃收录。

### SEO-04 robots.txt

- **检查什么**：根目录 robots.txt 内容是否正确；是否误禁应收录目录；是否声明了 Sitemap 位置。
- **怎么查**：访问 `/robots.txt`；用网管工具 robots 测试器验证具体 URL 是否可抓取。
- **合格**：文件存在（即使允许抓取全部也建议放空文件，避免服务器把错误页当 robots 返回 200）；每条 Disallow 独立一行；已写 `Sitemap:` 行；打印页、排序页等复制内容版本已被禁止。
- **不合格**：robots 缺失且有拼写/路径错误导致整目录被禁；多条 Disallow 写在一行。注意：robots 禁抓的 URL 仍可能以纯 URL 形式出现在结果中，要彻底不出现需配合 SEO-05。

### SEO-05 meta robots 标签

- **检查什么**：需排除收录的页面（付费内容、测试页、复制内容页）是否用了 `noindex`。
- **怎么查**：查看目标页面 `<head>` 中的 `<meta name="robots" content="...">`。
- **合格**：禁收录页写了 `noindex`（保留权重传递可不加 `nofollow`）；正常页面不写 meta robots（`index,follow` 等于没写，属冗余）。
- **不合格**：想排除的页面只靠不加内链（不能保证不被收录）。

### SEO-06 nofollow 与权重分配

- **检查什么**：非必要页面（联系我们、隐私政策、登录/注册、帮助、排序链接）是否被 nofollow；页面重复指向同一 URL 的处理。
- **怎么查**：检查模板中链接是否带 `rel="nofollow"`；数每页指向首页的链接（logo、导航、页脚）。
- **合格**：搜索价值低的页面已 nofollow 或仅首页展示；首页第一个指向首页的链接（logo 图片）ALT 含首页目标关键词；核心内容页未被误 nofollow；页脚无完全匹配关键词堆积。
- **不合格**：全站权重大量流向隐私政策等无排名价值页面；页脚堆完全匹配关键词链接（近一两年常见惩罚原因）。注意 nofollow 是次要因素，根本靠 SEO-11 的合理架构。

### SEO-07 URL 静态化与 URL 设计

- **检查什么**：URL 是否静态/伪静态；参数数量；目录层次；长度；命名描述性；大小写；连词符。
- **怎么查**：抽查各层级页面 URL。
- **合格**：URL 越短越好；参数 ≤2～3 个；目录层次尽量少；文件/目录名具描述性（`/news/finance/` 而非 `/cat-01/`）；字母全小写；单词用短横线 `-` 分隔（不用下划线）；目录形式或文件形式统一其一。
- **不合格**：大量 `?a=1&b=2` 长参数 URL；大小写混用（Linux 区分大小写会致 404）；下划线分隔。短期做不到全静态就先减少参数。

### SEO-08 网址规范化（301 / canonical）

- **检查什么**：同一内容是否可通过多个 URL 访问（带/不带 www、带/不带 index.html、带/不带斜杠、http/https、带端口、参数顺序不同）。
- **怎么查**：列出上述变体逐一访问，用 `curl -sI` 查看状态码；检查全站回首页链接 URL 是否唯一。
- **合格**：确定唯一规范化网址（通常选一个主域名版本）；其他变体全部 301 到规范版；所有内链、XML 网站地图统一用规范 URL；重复/排序页面用 canonical 标签指向规范版（建议绝对地址）。
- **不合格**：变体并存且均可访问（10%～30% 的网上 URL 存在此问题），权重被分散、收录名额被挤占。改法：① CMS 只产生规范 URL；② 内链统一；③ 301 转向；④ canonical 标签辅助。注意 301 权重传递 Google 需 1～3 个月。

### SEO-09 复制内容

- **检查什么**：同站内内容相同/相似的多个 URL——打印版、排序页、Session ID 页、RSS 生成页、正文过短页（正文抵不过导航版权等通用部分）、URL 任意加字符仍返回 200。
- **怎么查**：网管工具 HTML 建议查重复标题/元说明；从正文随机取一句话加双引号搜索，看是否有多个页面包含。
- **合格**：一篇文章只对应一个 URL；复制版本已被 robots 禁抓或 noindex；正文有足够独特内容。
- **不合格**：存在可抓取的复制版本。改法：选一个版本允许收录，其余 robots/noindex 禁止；同款不同规格页面用 canonical；跨站转载加版权声明+原出处链接。

### SEO-10 网站地图

- **检查什么**：是否有 HTML 网站地图；是否有 XML 网站地图并已提交/在 robots 中声明。
- **怎么查**：访问 `/sitemap.html` 与 `/sitemap.xml`；查看 robots.txt 的 Sitemap 行与站长工具后台。
- **合格**：HTML 地图列出全站（小站）或主要一二级分类（大站）；XML 地图 utf8 编码、≤5 万条/10MB，超出用索引文件（最多 1000 个）；已通过站长工具提交。
- **不合格**：无地图，或地图与导航毫无区别却指望它救收录。注意 XML 地图只是辅助，不能代替良好结构保证收录。

### SEO-11 内部链接及权重分配

- **检查什么**：链接结构是否为合理树形（首页→分类→内容页；分类间互链；内容页链接回首页与本分类）；重点内页是否获得首页直链；翻页是否过深；导航锚文字是否用了目标关键词。
- **怎么查**：数内页离首页的点击距离；查看网管工具内部链接板块。
- **合格**：所有页面离首页 ≤4～5 次点击；重点内页在首页/侧栏有直链；内容多的大分类得到更多权重；翻页做了再次分类或跳页格式（1,2,3,4,5,10,20,30）；相关内容链接有随机性（「相关推荐」「标签聚合」，而非仅上下篇）；导航锚文字为 2～4 字分类目标关键词，可做同义词变化（电脑/计算机）。
- **不合格**：深层页面权重过低无法收录；老内容权重衰减无入口。改法：首页直链重点内页；下拉菜单扶持大分类；翻页再细分；给深层页面补少量外链帮助收录。

### SEO-12 404 页面

- **检查什么**：不存在页面返回的状态码；自定义 404 页的设计。
- **怎么查**：`curl -sI https://example.com/definitely-not-exist` 看返回码；访问一个乱写地址看页面。
- **合格**：返回真实 404 状态码；404 页保持全站模板，醒目提示错误原因，提供首页、重要分类、网站地图链接和站内搜索框。
- **不合格**：不存在页返回 200（被判大量重复内容）；404 时 301/JS/Meta Refresh 转向首页（被判与首页内容相同的重复页）。

### SEO-13 导航、子域名与面包屑

- **检查什么**：导航是否 HTML 文字、有面包屑、当前分类高亮；子域名 vs 目录的选择；页脚是否堆链。
- **怎么查**：查看各页面导航源码与页脚链接区；盘点子域名使用情况。
- **合格**：文字导航（CSS 做视觉）；大中网站使用面包屑；无页脚关键词堆积；除内容量巨大/品牌线独立等正当理由外尽量用目录不用子域名（子域名是独立站，权重分散）。
- **不合格**：JS/Flash/图片导航；页脚堆链；随意开子域名。

## C. 页面优化

### SEO-14 页面标题（Title）

- **检查什么**：独特不重复、准确相关、字数、是否堆砌、关键词位置、品牌名位置。
- **怎么查**：网管工具 HTML 建议列重复标题；抽查源代码 `<title>`（应紧接 `<head>` 之后）；搜索 "Untitled Document"/「未命名文件」类默认标题。
- **合格**：每页标题独特；≤30 个中文字（建议 15～20）；目标关键词在最前面，格式如「产品名-分类名-网站名」；简练通顺不堆砌；一页最多针对 3～4 个词，可用通顺词组组合；品牌/公司名放最后；翻页标题加「第二页-」前缀保持独特；无「欢迎光临」式废话。
- **不合格**：全站同一标题；超长被截断；堆砌不自然（「童装，童装批发，童装零售」式罗列）。

### SEO-15 描述标签（Description）

- **检查什么**：是否写了；是否与标题重复、堆关键词、不成句；长度。
- **怎么查**：抽查各页面 meta description；搜索结果中看摘要是否来自描述。
- **合格**：一两句通顺、准确、吸引点击的句子，含目标关键词；≤70 个中文字；每页独特。
- **不合格**：与标题重复、纯关键词罗列（这些情况搜索引擎会改为动态抓取正文，站长失去摘要控制权）。确实写不好就干脆不写。

### SEO-16 关键词标签（Keywords）

- **检查什么**：是否还在花精力维护。
- **结论**：主流搜索引擎均不使用，写了无意义。不用浪费时间写；CMS 应允许删除该标签。此项默认「不适用/通过」。

### SEO-17 正文中的关键词

- **检查什么**：词频、前 50～100 词、变化形式、语义相关词、分类页说明文字。
- **怎么查**：通读页面正文，核对关键词出现位置。
- **合格**：自然写作——篇幅不大出现 2～3 次、长文 4～6 次；第一段含关键词；适当使用同义词/近义词与语义相关词；关键词组完整按顺序出现；分类/频道页有至少两三段人工撰写的独特说明文字；关键词密度不必刻意关注。
- **不合格**：堆积关键词；正文过短抵不过模板通用文字；分类页只有内容列表无独特内容。核心是针对用户的自然写作。

### SEO-18 H 标签

- **检查什么**：H1 是否唯一且含最重要关键词；层级是否对应文章结构。
- **怎么查**：查看页面源代码 H1–H6 分布。
- **合格**：文章标题用 H1（全页仅一次）、含最重要关键词；小标题 H2 含辅助关键词；分类页 H1=分类名称，内容页 H1=内容名称（而非网站名）。
- **不合格**：CMS 全站把网站名放进 H1；大量滥用 H1/H2。

### SEO-19 ALT 文字

- **检查什么**：图片 ALT 是否简要说明内容并含关键词；logo 的 ALT。
- **怎么查**：查看 img 标签的 alt 属性。
- **合格**：每张图有描述性 ALT 且关键词出现一次即可；左上角 logo 的 ALT 含首页目标关键词（它常是页面第一个指向首页的链接，ALT 相当于锚文字）；图片作为链接时 ALT 等于锚文字。
- **不合格**：ALT 缺失或堆砌多个关键词。

### SEO-20 精简代码

- **检查什么**：CSS/JS 是否外置；注释；嵌套表格；文件大小；链接数。
- **怎么查**：查看源代码体积与结构。
- **合格**：CSS 定义样式且无重复内联定义；CSS/JS 放外部文件；注释删减；HTML 尽量小（Google 曾建议 <100KB、链接 <100 个）；实质内容集中在文件前部。
- **不合格**：大段 CSS/JS 挤在 head；格式代码占比过高稀释文字信噪比。

### SEO-21 内部链接及锚文字（页面级）

- **检查什么**：正文内链锚文字是否自然多样；锚文字位置分布。
- **怎么查**：抽查正文内链的锚文字与位置。
- **合格**：一部分完全匹配关键词锚文字 + 一部分自然多样化；分散在正文中（学习维基百科）。
- **不合格**：锚文字全部完全匹配（过度优化）；集中在页脚堆完全匹配关键词链。

### SEO-22 导出链接

- **检查什么**：是否「惜链如金」从不外链。
- **合格**：适当以相关锚文字链接到相关、高质量外部网站——既说明对方主题，也佐证本页相关性。
- **不合格**：全站零导出链接。改法：正文中自然引用权威外部资源。

### SEO-23 其他页面元素

- **检查什么**：W3C 验证、黑体/斜体、页面更新。
- **合格**：无严重 HTML 错误（警告可忽略，W3C 通过与否对排名无明显影响）；关键词适度黑体；有时效性内容定期更新以吸引蜘蛛回访。
- **不合格**：严重 HTML 错误致无法提取文字；滥用黑体斜体。

## D. 健康度与作弊信号（风险审查）

> 判定原则：作弊惩罚是**积分制**——单一涉嫌手法往往不致命，多种手法叠加达到门槛才被惩罚；不同网站惩罚门槛不同（大站容忍度更高，不要学大网站的做法）；今天没被抓不等于永远安全。黑帽/白帽本质是**风险度判断**而非道德判断。本部分适合已获得排名流量的网站定期自查。

### SEO-24 页面级作弊信号

- **检查什么**：隐藏文字（同色/近色文字、1px 微小文字、CSS `display:none` 移出屏幕）、隐藏链接、关键词堆积（标题/ALT/锚文字/HTML 注释）、桥页/门页、隐藏页面（Cloaking，对蜘蛛和用户返回不同内容）、301 以外的非常规跳转。
- **怎么查**：Ctrl+A 全选页面看是否冒出隐藏文字；检查 CSS 中隐藏元素及颜色代码（背景 #FFFFFF、文字 #FFFFFD）；改浏览器 User-Agent 伪装成蜘蛛对比内容；对比快照与当前页面；全站排查 301 以外的跳转。
- **合格**：以上均无；标题与正文通顺自然。
- **不合格**：发现即清除，宁可「去优化」也不要叠加信号。

### SEO-25 垃圾外链与买卖链接

- **检查什么**：博客/论坛群发留言链接（留言与主题无关、锚文字是目标关键词、群发模式）；买卖链接（主题不相关、链接突然出现/消失、位置在页脚或赞助商区）；赞助模板/付费软文链接落在主题混乱的网站。
- **怎么查**：反查自己网站外链来源（网管工具 + Ahrefs/Majestic）；看外链曲线是否骤增骤减。
- **合格**：外链来源主题相关、增长自然。
- **不合格**：清理可疑链接是长期工作；买来的链接不要指望突然撤掉就没事——撤得太整齐本身也是信号。

### SEO-26 链接农场、坏邻居与站群

- **检查什么**：交换链接页是否全是链接无内容；是否链接向已作弊被惩罚的网站（**坏邻居链向你没关系，你链向它才危险**）；自己控制的站点群是否交叉互链过度；服务器同 IP 邻居是否有大量作弊站。
- **怎么查**：交换链接前检查对方 `site:` 收录、搜对方网站名称是否排第一；盘点同 IP 站点。
- **合格**：无上述情况。
- **不合格**：撤掉指向坏邻居的链接；同 IP 邻居大量作弊站尽早换主机。

### SEO-27 锚文字过度集中

- **检查什么**：外链大量重复同一目标关键词锚文字；内链锚文字过度优化、页脚放大量含关键词内链。
- **怎么查**：统计外链锚文字分布。
- **合格**：健康状态是品牌名、「点击这里」等自然锚文字占相当比例（专家经验 85% 品牌锚文字很正常）；锚文字分布在正文而非集中页脚。
- **不合格**：自然化锚文字分布，主关键词全面下降时优先「去优化」。

### SEO-28 全站技术风险

- **检查什么**：robots.txt 与 noindex 是否被误删/误加（被整站删除时首先检查）；页面看似正常但蜘蛛访问返回 404/无响应；域名注册人近期变更/曾过期。
- **怎么查**：人工读 robots 代码 + 网管工具验证；用服务器头信息检查工具模拟蜘蛛访问；查 whois 历史。
- **合格**：无异常。

## E. 惩罚检测

### SEO-29 确认「是否被惩罚」

- **检查什么**：排名大幅下降时区分正常波动与惩罚。
- **怎么查**（按顺序）：
  1. `site:` 指令搜域名——无任何结果 = 被严重惩罚删除（或 robots/服务器问题）；
  2. 搜索网站独特名称/品牌词——排第一的不是自己 = 通常被惩罚；
  3. 搜索网站特有文字（电话、邮箱、备案号）——第一不是自己 = 被某种形式惩罚；
  4. 检查蜘蛛来访次数/频率是否大幅下降（网站规模与更新速度未变时）；
  5. 关键词**全面大幅**下降（前十掉到几十页后）才可能是惩罚；部分升部分降很正常；从第一页掉到第二页一般只是算法变动或对手变强。
- **处置顺序**：排名下降先按兵不动一个月左右（可能是算法调整会回摆），1～2 个月仍下降再按 D 部分逐项排查：robots → 服务器邻居 → 转向 → Meta → 彻底去优化 → 清理可疑链接 → 检查重复内容。严重惩罚恢复率低，必要时放弃域名重建。

## F. 效果监测与优先级

### SEO-30 监测基准与网站目标

- **检查什么**：SEO 实施前是否设定了监测基准（记录原始表现数据）；网站目标是否明确、单一、可测量、可行动。
- **合格**：目标是「最想让浏览者做的那件具体的事」（下单/订阅/下载/联系），不是「流量增长 10%」这类展望；同时周期性记录主要竞争对手的同口径数据（对手也在优化，只看自己数据会误判水平）。
- **注意**：SEO 是长期策略，正常周期至少半年到一年；搜索流量占商业网站总流量 70%+ 本身是风险信号，需开拓其他流量来源。

### SEO-31 非流量指标体系

- **检查什么**：总收录数（`site:`）、特征页面收录（首页+典型分类页+典型内容页逐一查 URL）、关键词排名（几十~几百个词固定记录）、外部链接（总链接数/总域名数，看趋势不查每天）、转化与销售。
- **合格**：选定一种查询方法后坚持使用（不同方法间数字不可比）；每周/每月固定记录；重点看趋势与排名流量升降的因果关系。

### SEO-32 流量分析

- **检查什么**：访问数与跳出率（普通信息站/电商达 60% 左右是警讯，要定位高跳出页面）；流量来源三构成（直接访问/推介/搜索）；最常见进入页面是否为计划内优化的重点页；关键词流量细分（哪些词带来流量大/黏度高/转化率高、哪些是意外的高质量词）；长尾效果。
- **合格**：大中型网站前 10 个关键词占搜索流量不超过 50%——超过说明内链权重分配和基本优化有重大问题。
- **怎么用**：意外流量词可扩展成栏目/专题；发现来自陌生网站的点击流量，主动联系建立链接机会。

### SEO-33 优先级排序

- **检查什么**：改进建议是否按正确优先级执行。
- **原则**：
  1. **基本问题优先（95/5 原则）**：先确认关键词研究、收录/结构内链、Title/H1、正文关键词、原创性、一两个拿手的外链方法是否到位；细节优化贡献 ≤5%；
  2. **用数据找高 ROI 点**：优先做「第 2 页最前」和「第 1 页 6～10 名」的关键词——稍微调整就能进第一页，流量成倍增长；第 7、8 页的词不值得投入；
  3. **风险消除优先于锦上添花**：出现 D 部分叠加作弊信号应优先清理；关键词全面下降时优先「去优化」；
  4. **优先整站优化而非单个关键词排名**：真正带来大量流量的是长尾；
  5. **平衡优先于极致**：任何优化因素不应显得异常突出，宁可少而持续，不做突击。

## 本检查覆盖不了什么

- 关键词研究与竞争分析（属于 SEO 策划，不是上线体检范畴）；
- 外链档案的定量分析（需 Ahrefs/Majestic 等付费工具）；
- 移动端体验与 Core Web Vitals（可参考 Lighthouse，另行专项检查）；
- 结构化数据（Schema.org）与现代搜索特性——本清单基于经典方法论，未覆盖 AI 搜索/摘要时代的增量做法。
